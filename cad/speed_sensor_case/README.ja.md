# Pico 2 Wスピードセンサケース 初号設計

Pico 2 Wと同じ51×21 mmのユニバーサル基板に、MPU-6050、ピンソケット、
バッテリー、ピンヘッダ付きPico 2 Wを実装した、全高19 mmのアセンブリを収容する。
ケース本体とホイール取付サドルを分離し、ハブ径だけを変更して再利用できる構造とする。

## 構成

| 部品 | 役割 | 推奨材料 |
| --- | --- | --- |
| `body` | 電子部品の収容、基板支持、サドルとの接続 | PETG、最終版はASA |
| `lid` | 防滴蓋、雨返し、補助ストラップガイド | PETG、最終版はASA |
| `gasket` | 蓋と本体のシール | TPU 95Aまたは0.8 mmシリコンシート |
| `saddle` | ハブ曲面への追従、結束バンド固定 | PETG/ASA＋別体ゴムシート |

OpenSCADファイルは`part`を`body`、`lid`、`gasket`、`saddle`のいずれかに
変更して各部品をSTL出力する。`assembly`では組立状態を確認できる。

## 生成済みSTL

`stl`ディレクトリに初回試作用ファイルを出力している。

| ファイル | スライサー上の外形 | 材料 |
| --- | --- | --- |
| `speed_sensor_body.stl` | 63.0×26.8×23.8 mm | PLAで嵌合確認、走行用はPETG/ASA |
| `speed_sensor_lid.stl` | 66.1×29.9×4.0 mm | PLAで嵌合確認、走行用はPETG/ASA |
| `speed_sensor_gasket.stl` | 62.2×26.0×0.8 mm | TPU 95A |
| `speed_sensor_saddle.stl` | 38.0×34.0×8.0 mm | PLAで形状確認、走行用はPETG/ASA |

OpenSCADのManifold検査では、4ファイルとも`Status: NoError`の閉じたソリッドとして
出力できている。サドルの`hub_diameter = 32.0`はKsyrium Elite S前輪の現物採寸前の仮値である。

## 基準寸法

| 項目 | 初期値 |
| --- | ---: |
| 実装品 | 51.0×21.0×19.0 mm |
| 内部空間 | 52.0×22.0×19.8 mm相当 |
| 本体外形 | 63.0×26.8×23.8 mm（概算） |
| 蓋最大外形 | 66.1×29.9×4.0 mm |
| 蓋込み高さ | 約27.0 mm |
| サドル | 38.0×34.0×8.0 mm |
| 対象ハブ径 | 32.0 mm |
| 総高さ | 約35 mm＋ガスケット圧縮分 |

本体の両端を長くしているのは、電子部品空間から分離した位置に蓋用M3ネジを
置くためである。ネジは2本なので、これは水没対応ではなく雨天走行を想定した防滴構造である。

## MAVIC KSYRIUM ELITE Sへの適用

Mavic公式製品シートで確認できるKsyrium Elite Sは、前輪が18本ラジアルスポーク、
アルミ製ハブボディ、QRM+調整式カートリッジベアリング、6001ベアリングを使う。
公式分解図では前輪ハブ中央が左右対称の円筒に近く、本サドル方式を適用しやすい。

後輪は20本Isopulse組みで、FTS-Lフリーハブを持つ非対称構成である。スポークと
フリーハブ側の空間が複雑になるため、初号機は前輪ハブ中央へ取り付ける。

公式資料にはハブ胴の外径と中央直線部の長さが記載されていない。このため、
`hub_diameter = 32.0`は仮値であり、確定寸法ではない。製品写真と分解図を踏まえ、
フランジ間へ収まりやすくするため、サドル長を当初の44 mmから38 mmへ短縮した。
ケース本体は63 mmあるので、両端がフランジやスポークの上へ張り出す。サドル高さ8 mmで
スポークを避けられるか、現物で必ず確認する。

最終サドルを出力する前に、前輪の次の3箇所を測る。

| 記号 | 測定箇所 | CADへの反映 |
| --- | --- | --- |
| D | ハブ中央、結束バンドが通る位置の直径 | `hub_diameter` |
| L | 左右フランジ間の、円筒に近い直線部分 | `saddle_x`を`L - 2 mm`以下にする |
| C | ハブ胴表面から、ケース端の真下を通るスポークまでの高さ | `saddle_h`と干渉確認に使う |

年式違いを識別する場合は、リムや取扱資料のホイール参照番号も記録する。Mavicの
2013年版公式シートでは前輪参照番号`325732`が掲載されている。

参考：Mavic公式
[Ksyrium Elite S 2013 FRONT製品シート](https://technicalmanual.mavic.com/tech-mavic/technical_manual/pdf/getProductSheet.php?co=US&declinaison=FRONT&filialenu=2&macronu=16002)

## ホイールへの取付方向

ケースの長手方向をハブ軸と平行にする。サドル下面をハブ胴へ当て、
`strap_x`位置にある左右一組の穴へ、4 mm幅の結束バンドを1本ずつ通す。
合計2本で固定する。

サドルとハブの間には、厚さ1～1.5 mmのEPDMまたはシリコンゴムを貼る。
これは滑り止め、寸法差吸収、振動絶縁を兼ねる。ゴムを含めてハブ径を測り、
必要なら`hub_diameter`を変更する。

Pico 2 Wのアンテナ側は、金属製のハブフランジから可能な限り離れた側へ向ける。
取付後、ケース、結束バンド、ネジがスポーク、フォーク、ブレーキ部品に接触しないことを、
ホイールを手で一周させて確認する。

## 組立順

1. 実機の最大外形をノギスで再測定する。
2. サドルのM3インサート穴径を、使用するインサートに合わせる。
3. サドルへM3熱圧入インサートを2個取り付ける。
4. 本体内側からM3皿ネジ2本を通し、サドルへ固定する。
5. 底面レールへ薄い絶縁テープまたは0.5 mmフォームを貼る。
6. 電子部品アセンブリを挿入する。
7. 蓋裏へ薄いフォームを貼り、基板を軽く押さえる。部品には直接強い力を掛けない。
8. TPUガスケットまたは切り出したシリコンガスケットを置く。
9. 蓋をM3タッピングネジ2本で均等に締める。
10. サドルへゴムを貼り、結束バンド2本でハブへ固定する。

## 初回造形条件

- 寸法確認：PLA、0.20 mm積層、3周、15%インフィル
- 走行試験：PETG、0.20 mm積層、4周、30%インフィル
- 本体：底面をビルドプレートへ置く
- 蓋：STLは広い天面をビルドプレートへ置き、雨返しが上になる向きで出力済み
- サドル：STLはケースに接する平面をビルドプレートへ置く向きで出力済み
- TPUガスケット：0.20 mm積層、100%インフィル

## 造形前に確認する寸法

特に次の値は公称寸法ではなく、はんだ付け後の現物を測る。

- ユニバーサル基板端から突出するはんだ、ピン、配線
- Pico 2 W上面から最も高い部品までの高さ
- 基板下面のバッテリーまたは配線の突出
- MPU-6050と蓋の間隔
- 使用するM3皿ネジ頭部の高さ
- ハブの取付位置における実径と、平行部分の長さ
- ハブフランジ間でケースを置ける幅

実装品が51×21×19 mmを少しでも超える場合は、`assembly_x`、`assembly_y`、
`assembly_z`を実測最大値へ変更する。プリンタの寸法精度が低い場合は、
`xy_clearance`を0.5から0.7 mmへ増やす。

## 安全上の扱い

初走行は低速かつ交通のない場所で行い、数分ごとに結束バンドの緩みとケースの移動を
確認する。ケースは回転体に付くため、蓋ネジだけに頼らず、必要に応じて蓋のストラップ溝へ
細い補助バンドを通す。亀裂、層間剥離、バッテリーの変形が見つかった部品は使用しない。
